# Intro
This repo contains evironment configurations I like to use across various machines. Its intended for use with [Gnu Stow](https://www.gnu.org/software/stow/manual/html_node/index.html)
# Usage
## stow
1. Change the working directory to the repo.
2. Run `stow .`

## install zsh and omz
To install ohmyzsh run "setup_zsh.sh". This script will:
- install zsh
- set zsh as default shell
- remove previous ohmyzsh installations
- install ohmyzsh, some plugins and themes
